linux安装ffmpeg

本文目录
  1. 1. 安装yasm
  2. 2. 安装ffmpeg
  3. 知乎原文
作用：一般用ffmpeg命令来处理音频和视频，比如转码、裁剪等

这是 FFmpeg 4.4.1 的历史编译记录，不是新版的依赖清单。下面的版本号保留原文所用版本。

1. 安装yasm

安装ffmpeg之前需要先安装yasm。下载yasm源码包，解压并进入解压后的文件夹：

wget http://www.tortall.net/projects/yasm/releases/yasm-1.3.0.tar.gz
tar zxvf yasm-1.3.0.tar.gz
cd yasm-1.3.0

编译安装（按安装目录所需权限执行）。

./configure         # 加 --prefix=/xxx/yasm 可以指定安装目录
make                # 加 -j8 表示并行8路编译
make install

如果指定了安装路径，需要指定路径以便ffmpeg找到。

export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/xxx/yasm/lib
export PATH=$PATH:/xxx/yasm/bin

2. 安装ffmpeg

下载ffmpeg源码包，解压并进入解压后的文件夹：

wget https://www.ffmpeg.org/releases/ffmpeg-4.4.1.tar.gz
tar zxvf ffmpeg-4.4.1.tar.gz
cd ffmpeg-4.4.1

编译安装：

./configure   # 加 --prefix=/xxx/ffmpeg 可指定安装目录；--enable-shared 编译动态库
make
make install

原文在搭配 OpenCV 时开启了动态库。配置环境变量，以便使用ffmpeg命令和其它应用找到：

export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/xxx/ffmpeg/lib
export PATH=$PATH:/xxx/ffmpeg/bin
export PKG_CONFIG_PATH=$PKG_CONFIG_PATH:/xxx/ffmpeg/lib/pkgconfig

如果opencv安装时无法开启ffmpeg，检查PKG_CONFIG_PATH路径是否正确
