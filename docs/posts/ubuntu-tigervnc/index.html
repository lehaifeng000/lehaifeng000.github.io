Ubuntu远程桌面-虚拟桌面

团队服务器是Ubuntu系统的，系统版本是Ubuntu20.04，有远程桌面连接的需求，习惯了gnome不想换Xfce，远程工具用的是tigervnc，记录一下

本文是 Ubuntu 20.04 的历史配置记录。示例里的 VNC 端口只应给可信网络使用；需要跨网连接时，优先用 VPN 或 SSH 隧道，不要把 VNC 直接暴露到公网。

apt安装

先安装lightdm，ubuntu20自带的gdm3好像不太支持多桌面登录。

sudo apt update
sudo apt install lightdm

安装完会让选择，选择lightdm。

安装gnome-session-flashback和tigervnc服务器程序：

sudo apt-get install gnome-session-flashback
sudo apt-get install tigervnc-standalone-server

配置连接

  1. 执行 vncpasswd，设置连接密码。
  2. 先执行一次 vncserver 命令，初始化 ~/.vnc 文件夹，然后用 vncserver -kill :编号 关掉。
  3. 编辑 ~/.vnc/xstartup，填入下面的代码。
#!/bin/sh
unset SESSION_MANAGER
unset DBUS_SESSION_BUS_ADDRESS
export XKL_XMODMAP_DISABLE=1
export XDG_CURRENT_DESKTOP="GNOME-Flashback:GNOME"
export XDG_MENU_PREFIX="gnome-flashback-"
[ -x /etc/vnc/xstartup ] && exec /etc/vnc/xstartup
[ -r $HOME/.Xresources ] && xrdb $HOME/.Xresources
xsetroot -solid grey #设置背景色
vncconfig -iconic & #
gnome-terminal & #连接后会直接打开一个terminal窗口
nautilus & #连接后会直接打开一个文件窗口
gnome-session --session=gnome-flashback-metacity --disable-acceleration-check &

启动连接

TigerVNC 从 5901 开始用，可以多开几个端口，这里只开一个。如果由可信局域网直接连接，只在防火墙放行授权来源，例如：

sudo ufw allow from 192.168.1.0/24 to any port 5901 proto tcp

这里的 :1 指的是连接 1，用的端口就是 5901，-localhost no 允许局域网内的其他主机连接。

vncserver :1 -localhost no

客户端连接

  • TigerVNC 1.13.0 官方安装包
  • 原文 Windows 安装包
  • 原文 macOS 安装包
  • 原文 Ubuntu 20.04 安装包
  1. 打开安装的tigervnc客户端，输入服务器 IP:端口号，例如 192.168.1.100:5901。
  2. 点击连接，输入密码，即可连接上服务器桌面。

总结

使用到了一些命令，记录在这。

# 设置vnc连接密码
vncpasswd
# 启动vncserver虚拟窗口，其中:1可以改为:2、:3，端口依次对应5902、5903
vncserver :1 -localhost no
# 列出目前的窗口列表
vncserver -list
# 关闭某个vnc虚拟桌面，:1代表编号为1的桌面
vncserver -kill :1
