用 NumPy 手写一个 BP 神经网络

本文目录

  2. 损失怎样传回每一层
  3. 先跑一下 XOR

研一刚入门深度学习的时候，我用 NumPy 写了一个小网络来识别手写数字。前向传播还比较好理解，矩阵相乘过几层就能得到预测。反向传播费一点脑子，最后只算出一个损失，前面几层的每个权重又是怎么知道要改多少的？这里记一下这份代码里的做法。 项目仓库

这篇按 2021 年完成分类网络的时间归档。文中的运行命令、小数据集和梯度检查来自后来整理的版本。 2021 年的提交

一张图怎样变成 10 个分数

MNIST 一张图有 28 × 28 个像素。我把它摊成 784 个数，除以 255，再送进网络。第一层把 784 个输入变成 128 个数，过一下 ReLU，把小于 0 的值设为 0。第二层输出 10 个分数，对应数字 0 到 9。

比如标签是 7，就用 Softmax 把分数变成概率，再看第 7 类的概率。这个概率越大，-log(p[7]) 就越小。一批图都这么算，再取平均就得到训练用的损失。代码直接算对数概率，每行先减去最大的分数，这样求指数时更稳定。 Softmax 实现

损失怎样传回每一层

输出层的梯度可以直接用「预测概率减去 one-hot 标签」来算。比如前面那张图是 7，标签向量只有第 7 类是 1。批损失取了平均，所以在这里把梯度除以批大小，后面的层沿着这个梯度继续算。

全连接层前向算的是 Z = X @ W.T + b。反向拿到 dZ 后，dZ.T @ X 是权重的梯度，沿样本维度加起来是偏置的梯度，dZ @ W 则传给前一层。有 ReLU 的那层先按前向时留下的值做一次筛选，没过 ReLU 的位置梯度就是 0。

代码里就是一个倒序循环。每层算完自己的梯度，还要返回传给前一层的值。等这些梯度都算完，再用 W -= lr * dW 更新权重。看这两个文件基本就能顺完一趟。 训练循环 · 全连接层

先跑一下 XOR

想先看看网络能不能学起来，可以从 XOR 开始。就四条数据，两个输入不同时输出 1。程序会把它们的预测都打印出来。想再核对一步，可以给某个权重加、减一小点，各算一次损失，用差值估算梯度，再和反向传播算出来的值对比。下面几条命令在仓库目录里运行。

python -m pip install -r requirements.txt
python main.py --dataset xor
python check_gradients.py

跑通以后，可以换成仓库里那份 8 × 8 手写数字小样本，再试完整 MNIST。整理旧代码时还发现，旧版的评估循环切的是训练集。现在两个手写数字例子都在各自独立的测试集上算准确率。 数据和运行说明
