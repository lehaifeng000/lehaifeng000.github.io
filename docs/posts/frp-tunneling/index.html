frp内网穿透

本文目录
  1. 服务器端
  2. 客户端
  3. 服务器配置
  4. 连接方式
  5. 知乎原文

这是使用旧版 INI 配置的记录，不是当前版本的配置指南。部署时请按所用版本的官方文档配置认证、加密和访问限制，不要把示例端口直接向公网开放。

  • GitHub 地址：fatedier/frp
  • 下载压缩包，分别放到云服务器上和客户端上

服务器端

原文使用压缩包附带的配置，直接执行：

nohup ./frps -c frps.ini &

客户端

# 编辑客户端配置
vim frpc.ini
# 最后面添加
[ssh]
type = tcp
local_ip = 127.0.0.1
local_port = 22
remote_port = 6000

启动：

nohup ./frpc -c frpc.ini &

服务器配置

  • 原配置用到 7000 和 6000 两个端口，可以在两个 INI 文件里调整。
  • 如果云服务器有防火墙和安全组，两处都要核对。只放行授权来源。

连接方式

ssh -p 6000 username@云服务器ip
